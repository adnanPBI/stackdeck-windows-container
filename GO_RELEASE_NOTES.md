# StackDeck v0.6.0 GO release notes

## Final surgical hardening

This package starts from the uploaded `StackDeck-HyperV-Local-Container.zip` and preserves the newer r2-derived machine-scoped implementation already present in that source.

Final changes applied:

1. Restored the required `.github/workflows/release-windows.yml` release workflow that was present in the r2 patch but missing from the uploaded main source ZIP.
2. Kept the current immutable Windows runtime lock, ProgramData config root, LocalMachine DPAPI storage, stdin SMB secret flow, per-machine NSIS mode, signed payload verification, and client qualification controls.
3. Removed disconnected legacy `crates/stackdeck-gui` and `crates/stackdeck-desktop` source trees from the release handover so there is one desktop control plane: Tauri under `desktop/stackdeck`.
4. Removed generated `desktop/stackdeck/dist` from source handover; it is regenerated by `npm ci` / Vite during release build.
5. Corrected stale documentation that still described CurrentUser DPAPI and a fixed D: VM root.
6. Extended installer payload verification with an explicit `-SkipSignature` mode for unsigned **local-only** qualification. Signed verification remains the default and is still mandatory for publishable releases.
7. Added `15-Build-Local-Go-Package.ps1` to build the current CLI, hive, Tauri desktop, MSI and NSIS artifacts together, verify embedded payload hashes, and emit a local package with SHA-256/provenance.
8. Added `16-Ensure-Prebuilt-Runtime-Prereqs.ps1` so a prebuilt/installed client can check Hyper-V runtime prerequisites without requiring the Rust/Node development toolchain.

## Windows-only release gates

A Linux packaging session cannot truthfully execute the Windows MSVC/Tauri MSI/NSIS bundler or a real Hyper-V VM. Therefore final local functional acceptance is completed on the target Windows 11 Hyper-V host by running:

```powershell
.\scripts\windows\15-Build-Local-Go-Package.ps1
```

then installing one generated installer, initializing the runtime, and running:

```powershell
.\scripts\windows\11-Verify-Installed-Client.ps1 -SkipSignature `
  -Output .\stackdeck-client-functional-qualification.json
```

For a client/public production release, use the signed workflow and rerun qualification without `-SkipSignature`.
